# 雙人旋轉碰碰車 (Spin Sumo)

熱血刺激的同機雙人旋轉碰碰車！一鍵操作：放開旋轉瞄準，按住全力衝刺！將對手撞出擂台，搶奪隨機道具，先得3分獲勝！支援單人挑戰AI與雙人同螢幕對戰。

## 遊戲特色
- **一鍵微操（One-Button Control）**：放開旋轉調整角度，按住全力直線衝刺！
- **超彈性剛體碰撞（Juicy Physics）**：衝量物理碰撞、側面弱點暴擊擊飛、擂台外傾滑落重力。
- **4大隨機突發道具**：巨無霸相撲、渦輪加速、溜冰滑油、定時炸彈。
- **全端跨裝置相容**：
  - 電腦桌面：P1 `[A]` 鍵，P2 `[L]` 鍵，物理無衝設計。
  - 行動裝置：螢幕兩端獨立觸控區域，支援多點觸控（Multi-touch）。
- **單人挑戰 AI**：具備三級難度（簡單/普通/相撲大師）與前瞻安全射線決策機。
- **純 Web Audio 合成音效**：零外部音頻素材，體積極致精巧。
- **標準 Playroom 接入**：嚴格符合 Playroom 平台接入標準（commit `3728de1c50d4b0263f9f5f279d33d5d205a385fa`）。

## 本地開發

```bash
npm install
npm run dev
```

## 建置與打包

```bash
npm run build
```
產物將輸出至 `dist/`，包含 `game.json`、`index.html`、`cover.png` 與相對資源。
