# 雙人旋轉碰碰車 (Spin Sumo) - v1.3.0

熱血刺激的同機雙人旋轉碰碰車！一鍵操作：放開自轉瞄準，按住全力衝刺！將對手撞出擂台，搶奪隨機道具，先得3分獲勝！支援單人挑戰AI、雙人同機對戰，以及全新「大獎賽巡迴盃模式 (Tournament Cup)」！

## v1.3.0 新增特色 (Wave 4)

1. **大獎賽巡迴盃模式 (Tournament Cup Mode)**：
   - 經典三連戰盃賽模式：依序在水泥擂台、極地溜冰場、熔岩工廠展開 BO3 巡迴對決，累積獎盃積分奪冠！
   - 即時展示巡迴賽進度（Stage 1/3, Stage 2/3, Stage 3/3）、分站獎盃比分與專屬大獎賽總冠軍加長勝利號角！

2. **4 款特色碰碰車型選擇 (Vehicle Classes)**：
   - **極速刺客 (Speedster)**：轉向極快、衝刺速度 +25%，機動性極高，但質量較輕易被彈飛。
   - **裝甲巨獸 (Juggernaut)**：質量 +50%、撞擊抗擊退極高，宛如移動堡壘，轉向衝刺稍慢。
   - **漂移之王 (Drifter)**：甩尾摩擦極小、衝刺自帶雙渦輪噴射尾焰，靈動滑行。
   - **經典平衡型 (Classic)**：標準均衡全能屬性，手感扎實穩定。

3. **戰術道具與視覺反射升級**：
   - **戰術空投核彈 (Tactical Bomb)**：擂台中心定時空投 5 秒定時核彈，支援碰碰車推擠撞開轉移爆心，倒數完畢引發震撼蘑菇雲超強衝擊波！
   - **車頭動態聚光燈束 (Car Headlights)**：隨車身旋轉的半透明扇形夜戰動態地面聚光燈。
   - **金屬烤漆高光反射 (Dynamic Metallic Specular Reflection)**：車體金屬亮面鏡面反光弧光，質感大幅提升。

4. **智慧相撲宗師 AI 升級**：
   - 具備預測攔截、崖邊誘敵回正，以及主動規避倒數戰術核彈的生存決策！

## 操作說明

- **電腦鍵盤**：P1 `[A]` 鍵，P2 `[L]` 鍵。
- **行動裝置**：觸控螢幕左右分區獨立衝刺，支援多點觸控。

## 本地開發

```bash
npm install
npm run dev
```

## 建置與打包

```bash
npm run build
```

產物輸出於 `dist/`，包含 `game.json`、`index.html`、`cover.png`、`playroom-sdk.js` 與打包資源。
